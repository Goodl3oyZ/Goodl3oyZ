## 🖥️ HomeLab & Infrastructure

I rebuilt an old PC into a **Proxmox VE HomeLab**, using virtual machines and containers to deploy and operate my projects.

- **Networking:** Cloudflare Tunnel for external access without directly exposing application ports; Tailscale for private connectivity.
- **Deployment:** Docker Compose, Nginx/Caddy, and GitHub Actions.
- **Monitoring:** Grafana and Dozzle for monitoring and log inspection.
- **Local AI:** Ollama and Open WebUI, with hands-on exploration of RAG, vector databases, and local LLM deployment.
- **Systems engineering:** Learning to diagnose CPU, GPU/VRAM, memory, storage, networking, and container resource constraints.
