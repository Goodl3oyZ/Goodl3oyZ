### 🚀 Featured Project — GymBRO E-commerce

<a href="https://shop.flukelnwza.online"><img src="https://img.shields.io/badge/Live-shop.flukelnwza.online-b8f72b?style=flat-square&logoColor=black"/></a>
<a href="https://github.com/Goodl3oyZ/WebEcommerce"><img src="https://img.shields.io/badge/Source-WebEcommerce-181717?style=flat-square&logo=github"/></a>

A full-stack online store built and deployed on my own home server.

- **Stack:** Next.js · Node.js/Express · PostgreSQL (Drizzle) · Redis · Socket.IO · S3 storage
- **Payments:** Omise card (3-D Secure) and PromptPay QR, verified webhooks, automatic refunds and expiry
- **Commerce:** cart, checkout with stock reservation, coupons, loyalty points, shipping zones and tracking
- **Real-time:** live order notifications and customer-support chat
- **Reviews:** verified buyers only, rewarded with points once per product
- **Security:** email verification, OAuth (Google/GitHub), login lockout, rate limiting, PDPA privacy pages
- **DevOps:** Docker Compose, Cloudflare Tunnel, CI/CD with GitHub Actions → signed webhook deploy with health check and auto-rollback
- **Quality:** 258 automated API tests covering all 274 routes
